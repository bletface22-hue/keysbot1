# Техническое задание

## Проект
Telegram-бот для продажи товаров с каталогом, оплатой, ручной и автоматической выдачей, системой ролей, сменами работников и расширенной админ-панелью.

---

## 1. Общая цель
Разработать Telegram-бота для трех групп пользователей:
- покупатели
- работники
- администраторы

Система должна поддерживать:
- каталог товаров с фотокарточками
- редактирование карточек товаров
- оформление заказа через кнопки
- оплату через бота
- ручную выдачу для отдельных категорий
- авто-выдачу для отдельной категории
- прием ICC-ID для SIM-заказов
- чат между покупателем и исполнителем
- рейтинг покупателей
- роли и рабочие смены
- распределение заказов только активным работникам
- управление категориями, товарами, ценами и стоком
- статистику
- массовую рассылку
- редактирование текстов и кнопок через админ-панель

## 2. Категории каталога
Поддержать 4 категории:
1. SIM — ручная выдача + обязательный ICC-ID
2. GU — ручная выдача через диалог
3. BANK — ручная выдача через диалог
4. Использованные GU — авто-выдача txt из стока

## 3. Роли
Независимые роли:
- `buyer`
- `worker`
- `admin`

Допустимые комбинации:
- только worker
- только admin
- admin + worker

Правило назначения заказов:
- если есть `worker`, заказы приходят только при активной смене
- если `admin + worker`, то также только при активной смене
- если только `admin`, автоматические назначения не приходят

## 4. Главное меню
После `/start`:
- Профиль
- Каталог
- Пополнить
- Сделать заказ
- Рейтинг
- Поддержка

Рекомендованная раскладка:
- 1 ряд: Профиль | Каталог
- 2 ряд: Пополнить | Рейтинг
- 3 ряд: Сделать заказ
- 4 ряд: Поддержка

## 5. Каталог и карточка товара
Карточка списка:
- фото, название, краткое описание, цена, категория, доступность
- кнопки: «Подробнее», «Купить»

Полная карточка:
- фото
- название
- полное и краткое описание
- цена
- категория
- параметры
- суммы/варианты
- время обработки
- примечания
- кнопки: «Купить», «Назад»

Редактирование товара через админку:
- название, фото, описания, стоимость, категория
- активность, тип выдачи
- доступные суммы, min/max
- сортировка

## 6. Оформление заказа (базовый поток)
1. Каталог
2. Категория
3. Товар
4. Карточка
5. Купить
6. Параметры
7. Сумма/вариант
8. Подтверждение
9. Счет на оплату
10. Оплата
11. Запуск сценария категории

## 7. Оплата
Требования:
- создание счета в боте
- автопроверка статуса оплаты
- защита от двойного зачисления
- логирование оплат и ошибок
- хранение статусов в БД

После успешной оплаты:
- заказ -> «Оплачен»
- уведомление пользователю
- запуск сценария обработки

## 8. SIM-сценарий
После оплаты бот запрашивает ICC-ID:
> «Пришлите ICC-ID одним сообщением. Одна строка = один ICC-ID.»

Обработка:
- принять одно сообщение
- разбить по строкам
- удалить пустые
- сохранить в заказ
- подтвердить прием

Назначение исполнителю:
- только worker на смене
- round-robin или первый свободный

Карточка заказа для исполнителя:
- номер, дата/время, категория, товар, сумма, параметры
- ICC-ID списком
- данные покупателя + рейтинг и статистика
- статус + дедлайн
- кнопки: Выполнить, Отказаться, Продлить

Продлить:
- +1 ч, +3 ч, +6 ч

После «Выполнить»:
- статус «В работе»
- фиксируется исполнитель
- таймер 3 часа
- уведомление покупателю

При таймауте:
- «Просрочен» / «Отменен по таймауту»
- желательно возврат средств

Завершение:
- кнопка «Заказ выполнен»
- запрос «Пришлите договоры»
- загрузка файлов
- «Это все договоры»
- отправка файлов покупателю
- «Заказ выполнен, спасибо за покупку»
- статус «Исполнен»
- предложение оценить покупателя

## 9. GU/BANK-сценарий
После оплаты:
- назначение активному worker
- открытие диалога buyer <-> worker в рамках заказа
- поддержка текста, фото, документов
- завершение по кнопке «Заказ выполнен»
- уведомление пользователю
- выставление рейтинга покупателю

## 10. Использованные GU (авто-выдача)
После оплаты:
- выбрать нужное кол-во строк из стока
- сформировать txt
- отправить покупателю
- отметить строки использованными
- уменьшить остаток

Загрузка стока через админку:
- txt-файл
- каждая непустая строка = единица стока

## 11. Профиль
Показывать:
- Telegram ID, username, дата регистрации
- баланс
- заказы, выполненные заказы, замены, пополнения
- рейтинг

Кнопки:
- История заказов
- Пополнить баланс
- Мой рейтинг
- Назад

## 12. Рейтинг
- шкала 1..5, хранить среднее 1.0..5.0
- выставляет исполнитель после заказа
- хранить: оценка, заказ, кто выставил, дата, комментарий
- показывать: профиль, карточка заказа, админка, карточка замены

## 13. Замены
Для покупателя после завершения:
- кнопка «Запросить замену»

В заявке:
- причина
- комментарий
- файл/фото

Для review:
- расширенная карточка с данными заказа и клиента
- кнопки: Одобрить / Отклонить

## 14. Смены работников
Панель worker:
- Встать в работу
- Завершить смену
- Мои активные заказы
- Моя статистика

Старт смены:
- подтверждение «Вы выходите на работу? Да/Нет»
- фиксировать started_at
- статус «На смене»

Конец смены:
- подтверждение
- фиксировать ended_at
- новые заказы не назначаются
- активные заказы остаются за исполнителем

## 16. Тексты и кнопки (обязательный модуль)
Редактируемо без кода:
- тексты сообщений
- подписи кнопок
- разделы меню
- шаблоны уведомлений

У кнопок обязательные поля:
- `system_key`
- `label`
- `action_type`
- `is_enabled`
- `sort_order`

Шаблоны с переменными:
- `{username}`
- `{order_id}`
- `{amount}`
- `{status}`
- `{deadline}`
- `{product_name}`

Желательно:
- предпросмотр
- сброс к дефолтным значениям
