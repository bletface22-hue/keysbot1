# keysbot1

Репозиторий с проектной документацией для Telegram-бота продажи товаров (SIM / GU / BANK / Использованные GU).

## Документы

- `docs/technical_spec_ru.md` — полное техническое задание.
- `docs/developer_brief_ru.md` — сжатая developer-версия ТЗ (1–2 страницы).

## Рекомендуемый стек

- Python
- aiogram 3.x
- PostgreSQL
- SQLAlchemy
- Redis

## Рекомендуемая структура проекта

- `handlers/`
- `services/`
- `middlewares/`
- `keyboards/`
- `database/`
- `models/`
- `repositories/`
- `utils/`
- `admin/`
- `worker/`
- `user/`
- `config/`
